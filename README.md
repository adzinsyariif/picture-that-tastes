A zero-dependency program that draws one picture of food — one hero ingredient, rendered to make you hungry — and writes it to `/output/entry.png`. No network, no libraries, fully deterministic.

## Run it

```sh
node main.ts   # writes /output/entry.png (1024x1024 PNG, under 1 MiB)
```
